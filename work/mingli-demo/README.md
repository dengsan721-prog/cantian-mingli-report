# 参天命理综合研判 Demo

一个本地运行的命理报告应用。用户录入出生资料后，服务端完成农历换算、四柱排盘、真太阳时校验、资料质量分级与报告生成；每次查询会自动保存在本机，支持搜索、回看、打印和删除。

## 启动

```powershell
cd work/mingli-demo
python -m pip install -r requirements.txt
python server.py --port 8765
```

浏览器打开 [http://127.0.0.1:8765](http://127.0.0.1:8765)。页面必须通过本地服务访问，不能直接双击 `index.html`。

## 数据记录

- 查询记录保存在 `data/demo_records.db`。
- 数据库目录已加入 `.gitignore`，不会随代码提交。
- 每条记录保存原始输入、排盘结果、资料等级、校时候选和完整报告。
- 左侧可按姓名或出生地搜索历史记录。

## 精度规则

- 农历日期先换算为阳历，再交给统一排盘引擎。
- 有经度和 IANA 时区时，生成真太阳时校验结果。
- 出生时刻缺失时只生成三柱，不虚构时柱。
- 无时辰但具备至少 5 项、3 类人生事件时，只列出十二时辰候选，不自动选定。
- L1-L4 资料等级决定报告可以表达的上限，缺失项会在“专家质询与缺口”中列明。
