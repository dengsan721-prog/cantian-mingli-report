# 公开人物十万样本校验方案

## 一、目标

建立一个大规模公开人物样本库，用公开生辰资料与已发生人生事件反向校验命理理论偏差。

核心目的：

1. 检验理论规则哪些稳定，哪些容易误判。
2. 避免报告套模板、千篇一律。
3. 用真实事件训练纠偏逻辑。
4. 建立“命局标签 -> 现实表现 -> 偏差修正”的闭环。

## 二、数据范围

### 允许优先采集

- 已故历史人物
- 公开人物
- Wikidata 等开放结构化数据库中的人物资料
- 百科类公开条目中的出生日期、出生地、职业、死亡日期等结构化事实
- 已公开且具备来源链接的人生事件

### 谨慎采集

- 在世公众人物
- 名人访谈中披露的家庭事件
- 新闻报道中的财务、健康、婚姻事件

### 不采集

- 普通个人隐私资料
- 非公开出生时间
- 医疗隐私、身份证、住址、联系方式
- 来自付费课程、现代书籍、文章的长篇原文
- 违反网站条款或 robots 限制的数据

## 三、推荐数据源

### 1. Wikidata

优点：

- 结构化字段清晰
- 可用 SPARQL 查询
- 数据采用 CC0 公共领域贡献方式
- 适合大规模采集出生日期、死亡日期、出生地、职业、国籍、重要奖项等

局限：

- 很少有精确出生时辰
- 人生事件粒度不一定够细
- 数据质量需要交叉验证

### 2. Wikipedia / 维基百科

优点：

- 有人物生平、事件时间线、参考资料

局限：

- 文本内容有版权许可要求
- 不宜大段摘抄
- 事件抽取需要保留来源链接与摘要

### 3. 公共历史资料

适合已故人物校验：

- 历史人物年谱
- 公共百科
- 开放图书馆元数据
- 公开墓志、地方志索引

局限：

- 古代人物生日常有农历、真伪、时辰不明问题
- 年代久远，事件记录偏差大

每条公开人物样本应保存：

## 五、验证方法

### 1. 先做低精度统计

由于大多数公开人物没有出生时辰，第一阶段只用三柱或年月日：

- 日主分布
- 月令分布
- 职业类型分布
- 重大事件年龄段
- 已故人物寿命段与命局偏性关系

目标不是证明命理绝对正确，而是发现哪些规则更容易稳定对应现实。

### 2. 再做高精度样本

筛选有可靠出生时辰的人物，建立高精度子集：

- 出生时辰明确
- 出生地明确
- 关键事件年份明确
- 至少 5 个可验证人生节点

这类样本用于验证：

- 时柱影响
- 大运应期
- 子女、晚年、职业转折
- 重大冲合刑害触发

### 3. 建立偏差矩阵

每条规则都需要被案例检验：

- 命中：事件与规则预期一致
- 部分命中：方向对，但落点偏
- 未命中：规则不适用于该案例
- 反向命中：现实表现与规则相反
- 不可判定：资料不足

## 六、纠偏算法

当案例库发现大量偏差时：

1. 降低该规则置信度。
2. 增加适用条件。
3. 增加禁用条件。
4. 引入现实变量解释。
5. 在报告中加入“此判断需校验”的提示。

示例：

- 如果“财旺压身”在企业家样本中不表现为财务压力，而表现为资源掌控力，则规则要分化为“身弱财旺”和“身有根能任财”两类。
- 如果“官杀重”在不同性别、时代、职业中的表现差异明显，不能只写压力，而要拆成规训、职位、责任、制度、家庭权力结构。

## 七、隐私与合规边界

1. 只采集公开人物和开放数据。
2. 在世人物只保存公开事实，不保存隐私推测。
3. 不采集普通个人资料。
4. 不生成针对在世人物的负面确定性标签。
5. 不保存现代文章或书籍的长篇原文。
6. 保留来源链接和数据来源类型。

## 八、阶段计划

### 第一阶段：一万样本

- 以 Wikidata 为主。
- 保存出生日期、出生地、职业、死亡日期、主要成就。
- 只做三柱级别统计。

### 第二阶段：十万样本

- 扩展职业、国家、时代、事件类型。
- 引入事件抽取和规则偏差矩阵。

### 第三阶段：高精度时辰样本

- 人工筛选有可靠出生时辰的人物。
- 用于验证大运、应期、晚年、子女等精细模块。

### 第四阶段：反馈学习

- 将用户真实反馈与公开样本偏差矩阵合并。
- 输出模型规则置信度。
- 生成更个体化的报告。
