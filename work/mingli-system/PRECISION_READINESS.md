# 高精度研判准入标准

本系统把“排盘正确”“传统解释一致”“对未知结果有预测力”“建议对现实有帮助”视为四个不同问题。前三者不能因报告文字细致而自动成立，第四项必须接受用户后续反馈和现实专业意见检验。

## 个体资料硬条件

1. 原始出生记录：日期、原历法、是否闰月、来源及冲突版本均保留。
2. 时刻证据：精确到分钟的原始时刻、可信来源和误差范围；只知道时辰按约略处理。
3. 地点证据：出生地点、经纬度、IANA 时区及当年的法定时制、夏令时规则。
4. 历法审计：完成农历/公历转换、历史改历核验、节气边界和子初换日流派标记。
5. 双盘校验：保存当地钟表时主盘及真太阳时备选盘；时柱变化时不得合并成单一确定结论。
6. 事件资料：至少 5 个可核验有日期事件，覆盖至少 3 种类型，并记录来源、精度和敏感等级。

## 等级与可输出范围

| 等级 | 最低条件 | 可输出范围 |
| --- | --- | --- |
| L0 | 日期不足到日 | 资料整理，不生成命盘结论 |
| L1 | 完整出生日期 | 三柱结构与宽泛倾向 |
| L2 | L1 加出生地点 | 加入地点背景，仍不得使用时柱 |
| L3 | L2 加可靠时刻 | 暂定四柱；可列双盘，不得宣称精确应期已验证 |
| L4 | 精确时刻、坐标、历史时制与历法均核验，且事件达标 | 可进入结果规则校准，仍须通过独立测试 |

## 规则获得“可用”状态的条件

1. 规则必须转成可证伪假设，预先写明目标事件、时间窗、适用人群和排除条件。
2. 固定训练、验证、测试划分；测试集只在规则冻结后使用。
3. 报告非命理基线、样本量、95% 区间、效应提升和多重检验修正。
4. 按年代、性别、地区、职业和资料来源复核，不以总体平均掩盖分层失效。
5. 同一人物的资料不得跨集合泄漏；同源复制记录必须去重或聚类。
6. 回溯校时样本不能同时用于该人的结果验证。
7. 只有独立测试集表现稳定、外部复核可重复的规则，才可从“传统解释”升级为“统计支持”。

## 报告安全条件

- 每条结论保存规则编号、证据编号、置信等级、结论类型和验证状态。
- 医疗、法律、投资、生死灾祸等内容不得给出确定性诊断或替代专业意见。
- 资料不足时必须自动降级或阻断，不允许用模板语言补足缺失信息。
- 行动建议优先采用低风险、可逆、可观察效果的现实措施，并设置复盘日期。

## 当前状态

系统已具备严格资料评分、三柱/四柱快照、真太阳时双盘、固定数据集划分、年代分层、事件准入、验证协议、置信区间和报告闸门。当前公开样本的主要瓶颈仍是可靠出生时刻与多类型有日期事件不足，因此现阶段不能诚实地给出“高精准预测率”。系统会把该缺口显示为数据不足，而不是把安全规则的高合规率冒充预测准确率。

## 双轨时辰纠偏

- 正推轨：已知时辰正常排盘，同时隐藏答案运行反推模型，形成金标准盲测。
- 反推轨：未知时辰生成十二候选，只用校时事件评分，留出事件和未来事件负责验证。
- 原始时刻、反推时刻和核实时刻必须分栏保存，反推结果不得覆盖原始资料。
- 未经金标准盲测的模型只能输出候选集合；不得把对过去事件的最佳拟合写成确定时辰。
